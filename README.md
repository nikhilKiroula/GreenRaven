# 🌱 GreenRaven

A modern and responsive website developed for a **client project** as part of a team.

The website was designed and developed to provide the client with a professional online presence, clear presentation of their services and information, and a responsive experience across different devices.

## 🚀 Development

The project was developed using **React.js with Vite** for a fast and modern frontend development workflow.

The website was built with a responsive-first approach to ensure a consistent experience across:

```text
Desktop
   ↓
Tablet
   ↓
Mobile
```
